# GTA VI Shqip

Projekt statik në HTML, CSS dhe JavaScript. Synimi është të ndërtohet një bazë e strukturuar informacioni në gjuhën shqipe për GTA VI.

## Struktura

- `index.html` — faqja kryesore
- `css/` — stilet dhe paraqitja
- `js/` — logjika e ndërfaqes
- `data/` — të dhënat sipas kategorive
- `assets/` — imazhe dhe ikona

## Nisja lokale

Hap `index.html` në shfletues. Për zhvillim mund të përdorësh Live Server në VS Code.

## GitHub Pages

Ngarko përmbajtjen e kësaj dosjeje në root të repository-t. Te Settings → Pages zgjidh Deploy from a branch, branch `main`, folder `/(root)`.

## Rregull për burimet

Çdo informacion duhet të ketë burim dhe status të qartë: i konfirmuar, i raportuar, i rrjedhur ose spekulim. Mos i paraqit raportimet apo rrjedhjet si fakte zyrtare.
